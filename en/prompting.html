Prompt engineering basics

Prompting is the art of phrasing instructions for generative AIs to get the best possible results. Here are the fundamental principles:

Basic structure

  • Start with a clear action verb
  • Give the context and the desired format
  • Add relevant details
  • State the style or tone you want
  • Specify length or complexity

Advanced techniques

  • Prompt chaining (breaking into steps)
  • Few-shot prompting (included examples)
  • Role prompting (assigning a role)
  • Template prompting (using templates)
  • Iterative prompting (progressive refinement)

Useful tools

  • PromptPerfect — prompt optimization
  • PromptBase — prompt marketplace
  • PromptHero — prompt library
  • ChatGPT Prompt Generator
  • Midjourney Prompt Helper
